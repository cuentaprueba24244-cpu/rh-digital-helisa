Archivos planos para Helisa

Aquí termina el sistema: del RH de cada cierre sale el archivo que Helisa importa para generar la factura electrónica, y de cada recibo de caja sale el archivo con el que Helisa registra el recibo definitivo y cruza el pago contra la factura. Lucrecia descarga, importa en Transferencia de Datos y registra lo que Helisa devuelve. Las plantillas se configuran sin programar.
